# Celula Frontend

        Plantilla universal de especialidad con aislamiento de flujo.

        ## Roles simbolicos
        - Subgerente: Subgerente de Crecimiento
        - Supervisor: Supervisor Frontend
        - Especialista Principal: Forjador Frontend
        - Secretario: Secretario Frontend
        - Auditor: Auditor Frontend

        ## Enfoque
        - Division: subgerencia-crecimiento
        - Foco: renderizado, contratos visuales y smoke UI
        - Herramienta visible: Inspect

        ## Oraculos y dependencias

        - El Secretario mata loops, timeouts y deltas muertos.
        - El Auditor destila soluciones limpias y solo sube oro al grafo maestro.
